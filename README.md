# LeafWorld Resource Pack

Ресурс-пак с логотипом LeafWorld без нижнего подчёркивания для TAB, скорборда и заголовка меню ESC Minecraft Java Edition.
Метаданные совместимости: 1.21.4–1.21.11; в игровом клиенте не тестировался.

[Скачать ZIP](https://github.com/Agent1k-1/LeafWorld-rp/raw/refs/heads/main/LeafWorld-RP-1.21.4-plus.zip)

## Логотип Minecraft

Логотип Minecraft заменён на LeafWorld, надпись Java Edition скрыта. В стандартном GUI ширина LeafWorld около 144 пикселей, как в ESC. Серверный пак начинает действовать только после скачивания и применения. Для замены логотипа с запуска игры установите ZIP локально в `.minecraft/resourcepacks` и включите в настройках игры. Моды интерфейса могут менять отрисовку.

## Меню ESC

В русском и английском интерфейсе заголовок меню паузы заменён на логотип LeafWorld через перевод `menu.game`. Плагины не требуются; кнопки остаются прежними. Моды интерфейса могут переопределять заголовок.

## Префиксы OWNER и ADMIN

- OWNER: `` (U+E005), золотисто-оранжевый с белыми бликами.
- ADMIN: `` (U+E006), красный с белыми бликами.

```
/lp group owner meta setprefix 1000 "&f &7"
/lp group admin meta setprefix 900 "&f &7"
```

Если группы отсутствуют, сначала создайте их: `/lp creategroup owner`, `/lp creategroup admin`. Ссылка на ресурс-пак постоянная; после обновления меняйте только SHA-1.

## Префикс PLAYER

Серая плашка со светло-серыми буквами и белыми бликами: `` (U+E004).

```
/lp group player meta setprefix 100 "&f &7"
```

Если группы нет: `/lp creategroup player`. Выдать группу: `/lp user НИК parent add player`. Для отображения нужен принятый ресурс-пак и плагин чата/TAB, использующий префикс LuckPerms.

## Unicode

- TAB: `` — U+E001, для legacy-форматирования: `&f`
- Скорборд: `` — U+E002, для legacy-форматирования: `&f`

Логотипы TAB, скорборда и ESC сжаты по вертикали примерно на 40% без уменьшения ширины. ESC использует отдельный символ U+E003.

Белый цвет сохраняет цвета изображения. Вставьте символы в настройки вашего плагина TAB/скорборда. Игрок должен принять ресурс-пак.

## server.properties

```properties
resource-pack=https://raw.githubusercontent.com/Agent1k-1/LeafWorld-rp/main/LeafWorld-RP-1.21.4-plus.zip
resource-pack-sha1=e6ae1194b54f58c0bf707e25f6c0f4a5fe3b6595
require-resource-pack=true
```

Перезапустите сервер после изменения настроек. Для закрытого репозитория потребуется публичный хостинг ZIP: игровые клиенты должны скачивать файл без авторизации.
